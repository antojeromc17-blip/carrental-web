# Wayvero — Car Rental Management System (Frontend)

> **College B.Tech Computer Science & Engineering (CSE) Capstone Project**  
> React 19 + TypeScript + Vite + Tailwind CSS v4  
> Designed in **Google Stitch** (Dark Luxury Automobile Theme)

Please refer to the root project [`README.md`](../README.md) and [`DOCUMENTATION.md`](./DOCUMENTATION.md) for full project architecture, API documentation, step-by-step setup, and the complete Viva / Examiner Defense Guide.

### Quick Start (Frontend):
```powershell
# From the frontend root:
npm.cmd install
npm.cmd run dev
```
Runs on `http://localhost:5173`. Proxies `/api` to `http://localhost:8080`.
